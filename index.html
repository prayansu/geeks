Autoplay — install guide

Install the extension

Latest release v1.0.0
Download .zip ↗
01

Download and unzip

Download the .zip above and unzip it somewhere you'll remember, like a folder named autoplay-extension.

02

Open your extensions page

In Chrome or Edge, go to chrome://extensions (or edge://extensions).

03

Turn on developer mode

Flip the "Developer mode" switch, usually in the top-right corner of that page.

04

Load the unpacked folder

Click "Load unpacked" and select the unzipped folder from step 1. The extension appears in your toolbar right away.

Only install extensions from sources you trust. Since this isn't Web Store–reviewed yet, Chrome will show a standard developer-mode notice on the extensions page — that's normal for any unpacked install.
